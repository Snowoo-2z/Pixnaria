# Pixnaria

Pixnaria is a modern open-source coding platform concept for creating 2D games and animations with Python, nodes, and a custom engine.

Everything about Pixnaria — accounts, projects, likes, comments, reports,
bans, news, studios and public profile messages — is powered by **GitHub**.
There is no external database: visitors sign in with GitHub OAuth, projects
live as real GitHub repositories, and all community data is stored as JSON
files inside this very repository (on a dedicated `pixnaria-data` branch so
it never touches `main`). See [`SETUP.md`](SETUP.md) for how to configure
and deploy it.
